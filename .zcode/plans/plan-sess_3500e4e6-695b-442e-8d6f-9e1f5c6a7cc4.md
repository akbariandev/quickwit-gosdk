
# Quickwit Go SDK — Full Feature Implementation Plan

## Overview
Implement all Quickwit REST API features in the SDK, organized by endpoint group. The SDK will use the existing `resty` HTTP client wrapper pattern and idiomatic Go conventions.

---

## Git Flow Strategy
Each phase gets its own feature branch from `main`, fully tested, then merged via PR:
1. `feature/client-enhancements` → merged to `main`
2. `feature/complete-search` → merged to `main`
3. `feature/search-stream` → merged to `main`
4. `feature/search-scroll` → merged to `main`
5. `feature/delete-api` → merged to `main`
6. `feature/index-crud` → merged to `main`
7. `feature/ingest-api` → merged to `main`
8. `feature/cluster-api` → merged to `main`
9. `feature/tests-readme` → merged to `main`

Each branch will be squashed or merged with a descriptive commit message summarizing the feature.

## Phase 1: Client Enhancements (`client.go`, `errors.go`) — `feature/client-enhancements`
- Add functional options pattern: `NewClient(baseURL string, opts ...ClientOption) *Client`
  - `WithAPIKey(apiKey string)` — sets `Authorization: Bearer <key>`
  - `WithTimeout(duration)` — configurable HTTP timeout
  - `WithHttpClient(*http.Client)` — custom transport/tls
- Add error type wrapping for better error handling

**New file:** `errors.go`
```go
type QuickwitError struct {
    StatusCode int
    Message    string
}
```

## Phase 2: Complete Search API (`search.go`, `types.go`) — `feature/complete-search`

### New `types.go` — shared supporting types:
- `SortByField` struct (`field_name`, `order`, `missing_values_sort_option`)
- `SortByFieldDocOrder` struct
- `SnippetRequest` struct (`field_name`, `max_num_chars_per_fragment`)
- `HighlightRequest` struct (`field_name`, `fragmenter`, `max_num_chars`, `num_fragments`, `pre_tags`, `post_tags`)
- `Hit` struct (`JSON`, `Fragment`, `Score`, `PartialHit`)
- `SearchError` struct (`Message`, `Kind`)

### Extend `SearchRequest` struct with ALL Quickwit fields:
```go
type SearchRequest struct {
    Query                  string                 `json:"query"`
    DefaultOperator        string                 `json:"default_operator,omitempty"`
    SearchFields           []string               `json:"search_field,omitempty"`
    StartTimestamp         *int64                `json:"start_timestamp,omitempty"`
    EndTimestamp           *int64                `json:"end_timestamp,omitempty"`
    MaxHits                uint64                 `json:"max_hits,omitempty"`
    StartOffset            uint64                 `json:"start_offset,omitempty"`
    SortByField            *SortByField           `json:"sort_by_field,omitempty"`
    SortByFieldDocOrder    *SortByFieldDocOrder   `json:"sort_by_field_doc_order,omitempty"`
    Aggregations           map[string]interface{} `json:"aggregations,omitempty"`
    DocMapperFastField     string                 `json:"_source,omitempty"`
    SnippetFields          *SnippetRequest        `json:"snippet_fields,omitempty"`
    HighlightFields        *HighlightRequest       `json:"highlight_fields,omitempty"`
    TagFilters             []string               `json:"tag_filters,omitempty"`
    Filter                 string                 `json:"filter,omitempty"`
}
```

### Extend `SearchResponse` struct:
```go
type SearchResponse struct {
    NumHits           uint64        `json:"num_hits"`
    Hits              []Hit         `json:"hits"`
    ElapsedTimeMicros uint64        `json:"elapsed_time_micros"`
    Errors            []SearchError `json:"errors,omitempty"`
    Aggregations      interface{}   `json:"aggregations,omitempty"`
}
```

## Phase 3: Search Stream API (`search_stream.go`) — `feature/search-stream`

**Endpoint:** `POST /api/v1/{index}/search/stream`

```go
// Channel-based streaming (idiomatic Go)
func (c *Client) SearchStream(indexId string, req SearchStreamRequest) (<-chan SearchResponse, <-chan error)

// Callback-based streaming
func (c *Client) SearchStreamWithCallback(indexId string, req SearchStreamRequest, callback func(SearchResponse) error) error
```

- `SearchStreamRequest` extends base search with `fast_field`, `output_format`
- Reads NDJSON lines from response body, decodes each as `SearchResponse`
- Proper cleanup: closes channel on completion/error, supports context cancellation

---

## Phase 4: Scroll Search API (`search_scroll.go`) — `feature/search-scroll`

**Endpoint:** `POST /api/v1/{index}/search/scroll`

```go
func (c *Client) SearchScroll(indexId string, req SearchScrollRequest) (<-chan SearchResponse, <-chan error)
func (c *Client) SearchScrollWithCallback(indexId string, req SearchScrollRequest, callback func(SearchResponse) error) error
```

- `SearchScrollRequest` adds `scroll_ttl_secs` to base search fields
- Both channel and callback patterns supported (reuses streaming pattern from Phase 3)
